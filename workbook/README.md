# Separate Practice Workbook

Each chapter folder contains:
- `exercises.md`: Questions, Thinking Blueprints, Dry-Run Traces, Answers & Explanations
- `problems.py`: Starter stubs for you to solve in VS Code
- `solutions.py`: Reference solutions
- `test_problems.py`: `pytest` assertions to verify your `problems.py` code

Run tests for a chapter: `python -m pytest workbook/ch01_.../test_problems.py`
